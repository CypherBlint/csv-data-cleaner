CSV Data Cleaner v1

A Project for my developing portfolio as I progress through Python.

Purpose: For the user to upload a messy CSV file and have it cleaned of formatting and organizational issues.

Goals:  To submit a file by name and location.
        To clean file by: 
              removing duplicate entries 
              interpret and flag missing data, 
              standardizing any formatting such as dates, time, numbers
        To generate a report summarizing the changes made.
        To return a cleaned copy of the file to the user.
